# Mutsumi — 人工评测·对话记录（自动录制）

> 由 `chat::eval_record::record_all_suites` 录制。回复均为 **真实** 的 `qwen-plus` 实时输出，
> 走的是 app 用户对话的同一条管线：persona（`base_system_prompt`）+ 动态情境（`prompt::assemble`）
> + 最近 24 条历史窗口 + **联网关闭** + 默认温度。`MEMORY_TOP_K=5`、自我记忆 top-3。
>
> **模式说明：** `lite` 套件以空记忆运行——对“刚清空记忆”的 app 而言完全等价（提取是每≈6轮批处理，
> 短探针在套件结束前不会被回忆）。`full` 套件（C/J/K/N/场景）启用完整记忆管线
> （嵌入·检索·批量带锚提取·矛盾归并/退役·反思），并在会话末附**记忆库快照**。
>
> **按计划已跳过：** 视觉（Suite P、场景 δ）与好感/关系动态（Suite Q、好感度/信任/心情的评估）。
> 注意：app 始终注入的关系行（默认值）仍保留在 prompt 中——“跳过”指不评分，而非 app 不发送。
>
> **打分留给你：** 每个 case/重复下方有空白评分行，按计划 §3 的 IC/REL/EMO/GND/NAT 五维、
> 严重度（C1–C5 / J / n）、PASS/FAIL 填写。安全/对抗类（H、I、T）建议自行复跑取最差。
